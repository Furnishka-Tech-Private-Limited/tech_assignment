# Data Dictionary

All files are UTF-8 CSV with a header row. All values are fictional. Treat every column as text as delivered; types below are the *intended* types.

## leads.csv
| Column | Intended type | Notes |
|---|---|---|
| lead_id | text | Source-system id, unique per record (not per person) |
| first_name, last_name | text | May have inconsistent casing |
| email | text | Person identifier for matching; may be missing, invalid, padded or upper-case |
| phone | text | Free format; may be incomplete |
| company | text | |
| company_size | integer | Employee count; may be blank |
| industry | text | |
| country | text | Mixed spellings and codes |
| source | text | Acquisition channel (Website, Webinar, Referral, ...) |
| lead_status | text | New, Working, Qualified, Converted, Lost, Disqualified (casing varies) |
| created_date | date | Mixed formats: `YYYY-MM-DD`, `DD/MM/YYYY`, `DD-Mon-YYYY` |
| owner | text | Sales rep currently assigned; often blank |

## activities.csv
| Column | Notes |
|---|---|
| activity_id | Unique id (some rows are repeated) |
| lead_id | Links to leads |
| activity_type | `web_visit`, `email_open`, `form_submit`, `call`, `meeting`, `demo_request` |
| activity_date | Mixed date formats; some are in the future |

## opportunities.csv
| Column | Notes |
|---|---|
| opp_id | Unique id |
| lead_id | Links to leads |
| stage | Qualification, Proposal, Negotiation (open); Closed Won, Closed Lost (closed) |
| amount | Currency string; may include `$` and thousands separators |
| close_date | Expected (open) or actual (closed) close date |

## orders.csv
| Column | Notes |
|---|---|
| order_id | Unique id |
| lead_id | Links to leads |
| order_date | Date of purchase |
| amount | Currency string, as above |
| contract_end_date | When the subscription ends (basis for renewal) |

## tickets.csv
| Column | Notes |
|---|---|
| ticket_id | Unique id |
| lead_id | Links to leads |
| opened_date | Date opened |
| status | Open, Pending, Escalated, Closed |
| severity | Low, Medium, High |

## Relationships
`leads` (1) to (many) `activities`, `opportunities`, `orders`, `tickets` via `lead_id`.
A lead with at least one order is a **customer**.
